# 🍎 숫자 수확

8×8 숫자 격자에서 이어진 숫자를 골라 합이 10의 배수가 되면 수확하는 1분 게임입니다. 자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.

## 게임 소개

사과에 표시된 1~9 숫자 중 상하좌우로 인접한 숫자를 드래그해 선택합니다. 선택을 놓았을 때 합이 10의 배수면 수확한 칸마다 1점을 얻고, 위쪽 사과가 아래로 떨어지는 애니메이션 뒤 맨 위에 새 사과가 채워집니다. 보드에 빈칸 없이 60초 동안 높은 점수에 도전하세요. 새 최고 기록을 세우면 컨페티가 터지며, 기록은 현재 브라우저에 저장됩니다.

## 어떻게 만들었나요

HTML, CSS, Vanilla JavaScript를 별도 파일로 구성했습니다. Pointer Events로 마우스와 터치 드래그를 처리하고, 키보드 방향키와 Enter/Space 선택도 지원합니다. 최고 점수는 `localStorage`에 저장합니다.

## 실행 방법

`index.html`을 최신 웹 브라우저에서 열면 바로 플레이할 수 있습니다. 별도의 패키지 설치나 빌드 과정은 필요하지 않습니다.

## 커스터마이징한 부분

제한 시간을 1분으로 설정하고, 정확히 10이 아닌 10의 배수 합계를 허용합니다. 게임 화면을 HTML/CSS/JS 파일로 분리하고 사과 아이콘, 열 단위 낙하와 새 사과 보충을 적용했으며, 반응형 레이아웃, 최고 점수 저장, 신기록 컨페티, 키보드 조작을 추가했습니다.
